매매 전 점검
무조건 모든 조건을 만족시키는 종목만 매수한다. 애매하면 아예 사지 마라.
D+1 상따매매 시에는 2등주가 무너지지 않았는지 본다 — 위 카드에 2등주를 같이 띄웠다.
RSI 70 이상은 과매수 = 위험 가산. 매수 신호가 아니다.
손절은 평단가 기준 3:1. 익절 폭이 손절 폭의 3배가 안 되면 들어갈 자리가 아니다.
시장 ADR 은 참고 지표다. 판단을 ADR 로 결정하지 않는다.
