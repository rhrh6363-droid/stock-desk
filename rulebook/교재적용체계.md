## 1. 전체 흐름 — 장마다 맡은 역할과 내놓는 것

```
 0장 세팅      무엇을 띄우는가            → 프레임(월·주·일·60분·분), 기준선 하나, 지수 두 개
   ↓
 1~5장 재료    차트·매물대·수급·재료       → 프레임별 "사실" (위치·선·거래량·수급)
   ↓
 6~7장 선택    어떤 매매법인가             → 매매법별 조건 충족/미충족 → 적합·조건부·부적합·판정불가
   ↓
 8장 틀        얼마에 사고 팔고 버리나      → 진입·분할·손절·익절·매도 원칙·보유자 대응·물타기 판정
   ↓
 9장 덮개      시장이 허락하는가            → 장세·현금 비중·외부 변수 → 6~8장 결과를 덮어쓴다
   ↓
 10장 결론     최종적으로 무엇을 하나       → 포지션별 한 줄 + 원칙 위반 경보 + 목표 상한
```

**9장이 6~8장을 "덮어쓴다"는 순서가 핵심입니다.** 교재가 그렇게 말합니다.
- 7-5 [0]: "시장 — 이것이 틀리면 아래 전부 무효"
- 10-3 §5: "기법 전에 지수가 먼저다"
- 7-2 [0]: "지수가 하락 추세면 매매 중단"

그래서 분석기는 매매법 판정을 먼저 다 낸 다음, 9장 게이트로 걸러 10장 결론을 냅니다.

## 3. 1~5장 — 차트·매물대·수급·재료: 도구 전수와 가능성

표기는 다섯 가지입니다.
- **●** 분석기가 지금 계산합니다.
- **◐** 근사만 합니다(형태 인식, 해석 일부).

### 4-3. 제안 — 기본 스타일과 장세 스위치

**제안: 기본 = 단기스윙 군 (#8 눌림목 · #9 돌파 ④자리 · #10 음봉 바닥 · #11 기본 · #12 박스), 판정 프레임 = 일봉 20선 + 주봉 확인.**

1. **판정이 완결되는 것만 기본값으로 둔다.** 이 보고서는 장 마감 후에 나옵니다. #1·#2·#3·#6은 지수 3분봉·호가창 같은 장중 조건이 핵심이라, 보고서가 "적합"을 낼 수 없습니다. 단기스윙 군은 일봉 마감 + 60분봉으로 조건이 전부 닫힙니다.
