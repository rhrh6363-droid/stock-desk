### 손익비 3:1 이 성립하는 조건 (이 표의 핵심 귀결)

```
목표가 상한 = 일봉 파동 평균 10%, 최대 15%          <교재 7-5>
손익비 3:1  = 손절폭 × 3 = 목표폭                   <교재 6-5 · 사용자 확정>
  ↓
손절폭 ≤ 10% ÷ 3 ≒ 3.3%  (최대 15% ÷ 3 = 5%)
  ↓
즉 "손절폭 3~5% 안에 들어오는 자리"에서만 3:1 이 성립한다
  = 이격도가 가까울 때만 자리가 성립한다는 교재 논리와 정확히 일치
```

→ 목표가가 **현재가 +15% 를 넘으면** 그 자리는 손익비 조건 미달로 표시한다.

## 10. 캔들 패턴 확률 서열 (1-2 `<교재>`)

| 패턴 | 확률 |
|---|---|
| 캔들 하나만 | **50% 근처** |
| 작은 패턴 | 50~55% |
| 양봉이 전 캔들 중심 못 넘음 | 55~60% |
| 연속 음봉 + 역망치 + 갭상승 양봉 | 55~60% |
| **망치형** (하락 뒤 긴 아래꼬리) | 60% 이상 |
| **관통형** (중간을 돌파하며 마감) | 60% 이상 |
| **상승장악형** (음봉을 완전히 덮는 양봉) | 60% 이상 |
| **샛별형** | 60%대 |
| 이겨내는 음봉 **1개** | 60% |
| **이겨내는 음봉 3개** | **70~80%** ← 교재 최고 확률 |
| 도지 + 20일선 지지 | 단독 50% → 상승 쪽 |

**어떤 패턴도 80%를 넘지 않는다.** 화면에 확률을 표시할 때 이 상한을 넘기지 않는다.
